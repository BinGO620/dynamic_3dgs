## 结论

1. **去残影成功**：深度 L1 改善 3.1-3.8 倍（135→43cm 级），transition 序列
   LPIPS 全面改善——软静态一致性先验 + 足迹尺度 + 残差致密化达到设计目的。
2. **光度上限依旧（12-14dB）**，且已排除曝光因素。图像证据（/tmp/v3_cmp_9000.png，
   已存 evidence/）：frame 9000 相机近贴机器人，GT 一半像素是动态物体——
   **静态融合地图在动态物体近旁的视角存在不可消除的误差地板**（无该视角下的
   背景观测，地图无法也不应渲染出正确内容）。
3. 跨机冒烟（100帧/3k步）可达 13.9dB/16.3cm，说明全量 15k 步没有过拟合退化；
   60k 长跑（baseline_v3_long）用于检验"访问次数"杠杆。

## G0.2 复核与改判（A6）

原判据"static 序列 held-out PSNR ≥20dB"建立在该序列无动态物体的假设上。
实况：bonn_static 的机器人覆盖大量画面（尤其后半段近距视角），全帧指标
混入了**原理上不可重建的像素**。改判：

- G0.2 主读数改为 **depth L1 ≤ 50cm（全帧）+ 静区 PSNR ≥ 18dB（held-out，
  静态一致像素）**；全帧 PSNR 作为参考而非门槛。
- 当前 42.9cm 已过深度线；静区 12.2dB 未达，仍受细节锐度限制（见下一步）。

## 下一步（阶段0.5 继续）

1. 等 60k 长跑结果：若 PSNR 显著爬升（→15dB+），说明纯粹是访问次数不足；
   若平台在 ~12dB，则上**多视图批量**（4-8 视/步）与 **antialiased 光栅化**。
2. 静区 PSNR 的锐度缺口：怀疑 ED 深度在大 alpha 前景遮挡下的半透明混合 +
   足迹 2px 初始化仍偏大；做 1px 足迹消融。
3. G0.3 凹陷判据在 v3 数字上复核（removing 平滑凹陷已可见）。
4. 以上全过 → 阶段1 机制配对实验（生命周期臂 vs 本基线）。
