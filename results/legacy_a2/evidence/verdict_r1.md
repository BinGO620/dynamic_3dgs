# legacy_a2 verdict — 路线 Y 阶梯（2026-09-09 深夜，本机 2060）

## 判决：**路线 Y（offline 精修机制）证伪**——按预注册失败语义止损

预注册门槛：任一臂 ≥19dB 达标；全臂 ≤16.85 判伪。实测全臂 13.1-14.1dB，
**无一接近 base（stock 26k 随机视角色彩精修，16.646）**。

| 臂 | 精修配置 | PSNR | SSIM | dL1(cm) | n_gauss |
|---|---|---|---|---|---|
| **base(rev3)** | stock color_refine：随机视角、0.8L1+0.2DSSIM、无致密化 | **16.646** | 0.706 | 52.3 | 34854 |

## 归因（只写事实）

1. **精修期致密化摧毁几何**：a5 的深度 L1 224.8cm（base 52.3）——致密化
   + 全局 opacity reset 在已收敛地图上以重启的高 LR 运行，新点涌入 +
   不透明度清零，几何崩坏。与 Phase A rev4 探针（浮丝、191cm）同模式。
2. **深度损失项在精修期有害**：a1 vs a5 隔离出深度项本身 -0.6~-1dB 级
   （且 a1 的深度项在无覆盖像素按 |0−gt| 全额计损）。
3. **多轮确定性循环 vs 随机视角**：所有离线臂共有的退化成分；base 的随机
   采样保持最优。
4. 一致结论：**流式建图收敛出的地图处于强局部最优，任何"更努力"的精修
   （致密化/重置/深度监督/确定性调度）都在破坏它而非改进它**。30 帧
   冒烟的 18.05dB 是短序列假象（覆盖近满 + eval 帧紧邻训练帧）。

## 与既有关节的连接

- 阶段0.5 结论"访问次数杠杆证伪"（baseline_v3_long，+0.05dB）在第三种
  架构上第三次复现——**多轮/更长精修不是杠杆**。
- Phase A 判决"SLAM 流式语义=弱底座"仍然成立，但路线 Y 的修法（在流式
  地图上做离线精修机制）也被证伪。底座瓶颈在**建图期**（覆盖与初始化），
  不在精修期。
- 23.66 锚点（monogs-ours 魔改 backend）的差距来源进一步收窄：不在我测过
  的精修机制空间内，更可能在 backend 建图期的工程（per-gaussian 致密化
  knobs、prune 语义、窗口调度）——路线 X 的剩余价值上升。

## 补充（2026-09-10 凌晨）：移植 bug 修复后的复测

用户指出代码有 bug，审查发现 **map() prune 路径丢失 stock 的 monocular
守卫**（n_obs≤3 剪枝 stock 只对单目执行，RGB-D 不剪；我们凭空多剪），
另有 confirm-config 继承、config_used 先于 override 落盘等 6 处已修
（commit 403bef5）。

修复后复测（bonn_removing seed0）：

| 配置 | 带 bug | 修复后 |
|---|---|---|
| base（stock 精修） | 16.646 / 34854 gauss | **16.771 / 95619 gauss（3×）** |
| a5 | 14.145 / dL1 224.8 | 14.469 / dL1 224.2 |
| a2 | 13.892 / dL1 38.5 | 14.076 / dL1 39.5 |

**判决不变**：全臂仍低于修复后 base ≥2.3dB，路线 Y 证伪成立。修正两点
记录：①champion 底座 = 16.77dB / 96k 高斯；②"prune 吃新点"的主因是本次
修复的移植 bug（n_obs 剪枝），gaussian_th/size_threshold 是 stock 自有的
次要条件。
