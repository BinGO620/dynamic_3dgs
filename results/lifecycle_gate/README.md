# lifecycle_gate — 阶段1：地图生命周期门控机制（RGB-D）

## 四件套

- **假设**：v3 基线的静态地图仍含大量低共识壳体（软过滤只压暗到 15% 不透明度，
  仍在污染遮挡/颜色/深度）。给每个高斯挂出生帧+时序证据账本，退场门控
  （长期无静态证据支持 → 不透明度衰减/剪枝）与入场门控（新点需证据才转正）
  能同时改善静区渲染质量与残影。
- **判据（预注册）**：单变量配对，同 seed 同 config，removing/placing/kidnapping
  ×3 序列：
  - M1 静区 PSNR（psnr_static_cons）≥ v3+2dB
  - M2 depth L1 ≤ v3×0.8
  - M3 事件后凹陷恢复更快（凹陷半宽/深度）
  - 保护读数：事件前静态段与 kidnapping 静态段不退化（±0.3dB）
  - 安慰剂门禁：P1（随机时间戳账本，同剂量）必须无效（|Δ|<0.5dB）
- **配置**：C0=baseline_v3 复跑；P1=安慰剂账本；M-a=退场门控（证据 EMA 衰减
  → sigmoid 不透明度乘子 ×(0.9^age)，低于阈值剪枝）；M-b=M-a+入场门控
  （残差致密化新点先以"试用期"低不透明度入场，累计 ≥K 次静态一致才转正）。
- **预期**：M-a 主要吃 M2（残影深度污染）；M-b 主要吃 M1（静区锐度，
  减少壳体遮挡后 RGB 优化不受污染梯度拖累）；若两臂都不过安慰剂门禁 →
  机制在离线语境无因果效应，止损并记录（E0 单遍递增协议作为备选假设）。

## 运行矩阵

| 臂 | 序列 | seed | 状态 |
|---|---|---|---|
| C0 | removing/placing/kidnapping | 0 | 进行 |
| P1 | 同上 | 0 | 进行 |
| M-a | 同上 | 0 | 待机制实现 |
| M-b | 同上 | 0 | 待机制实现 |

## 第二轮（E0 单遍递增协议，2026-09-09 晚预注册）

**动机**：第一轮阴性可能被"多轮精调擦除残影"掩盖——离线随机采样让每帧被看
30 次，地图有充分机会覆盖/修复早期错误。SLAM 时刻表没有这种奢侈。E0 改为
**严格时序单遍**：训练帧按时间顺序处理，每帧仅在其自身映射窗口内被看
stream_k=40 次（对齐 MonoGS 量级的 per-keyframe 迭代），无重观测 epoch。

**假设**：单遍下，早期动态壳体不再被后续 epoch 修复，C0-e0 的残影将显著
恶化；生命周期门控（退场）此时才有因果空间。

**预注册判据**（同第一轮 M1/M2/M3+安慰剂门禁；对照=C0-e0）：
- 若 C0-e0 深度/PSNR 相对第一轮 C0 大幅恶化（协议效应存在）且 Ma-e0 在
  M2（depth ratio ≤0.8）上配对胜出 → 机制在 SLAM 时刻表下成立，主线转 E0；
- 若 C0-e0 未恶化或 Ma-e0 仍无效 → 离线语境下生命周期门控机制整体证伪，
  记入已排除方向，转攻静区锐度（多视图批量/antialiased）。

**矩阵**：{C0, P1, Ma, Mb} × {removing, placing, kidnapping}，seed 0，
双卡各 2 worker（GPU0=C0+P1，GPU1=Ma+Mb），skip 幂等。
