# verdict — lifecycle_gate Round-3（retire_ev=0.1）+ 三轮综合

## Round-3 结果（Mb 配置，retire_ev 0.2→0.1，stream_k=40）

| 序列 | C0-e0 PSNR/深度 | Mb-e0 | Mb-r3 (ev=0.1) |
|---|---|---|---|
| removing | 11.76 / 39.96 | 10.41 / 35.03 | 10.48 / 34.69 |
| placing | 9.03 / 41.76 | **10.01 / 38.20** | 7.86 / 39.54 |
| kidnapping | 10.61 / 55.85 | 9.82 / 55.30 | 8.72 / **61.24** |

r3 在 placing/kidnapping 均显著劣化（kidnapping 深度反升 5.4cm、覆盖率掉到 0.67）
——**退场越松伤害越大**，round-2 的 retire_ev=0.2 就是最优工作点。

## 三轮综合矩阵（对照 C0-e0）

| 发现 | 证据 |
|---|---|
| E0 单遍协议有效且更难 | C0-e0 比多轮 C0 低 ~1.5dB，配对基础成立 |
| 退场门控有真实因果效应 | removing 深度稳定 -12~13%（两阈值下复现） |
| 效应=trade 而非净增益 | 深度赢的同时 PSNR 输（removed 壳体也承担光度信号） |
| 净增益强序列依赖 | placing（box 后出现）双赢；kidnapping（绑架+重访）净负 |
| 阈值敏感方向不利 | retire_ev 0.2→0.1 全线变差 |
| 安慰剂始终干净 | P1 与 C0 差 ≤0.05dB（两轮） |

## 总判决（阶段1 前两轮+第三轮阈值迭代）

显式证据账本退场门控**未达预注册门槛**（M1 +2dB / M2 ≤0.8× 均未达成），
且不存在"调松就好"的改善路径。机制效应真实存在但本质是**深度-光度的
trade**，其净收益由序列的动态结构决定（placing 型受益、kidnapping 型受损）
——把它变成净增益需要"何时退场是安全的"判断，这正是 monogs-ours
deferred_commit（确认制+观察窗）要解决的问题，超出本仓库单变量范围。

**止损收口**。已排除：显式证据退场门控（两阈值 × 3 序列 × 2 调度）。
存活机制：A5 软静态一致性先验（出生不透明度调制）为本仓库最优生命周期机制。
