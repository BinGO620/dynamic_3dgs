# lifecycle_gate — 阶段1：地图生命周期门控机制（RGB-D）

## 四件套

- **假设**：v3 基线的静态地图仍含大量低共识壳体（软过滤只压暗到 15% 不透明度，
  仍在污染遮挡/颜色/深度）。给每个高斯挂出生帧+时序证据账本，退场门控
  （长期无静态证据支持 → 不透明度衰减/剪枝）与入场门控（新点需证据才转正）
  能同时改善静区渲染质量与残影。
- **判据（预注册）**：单变量配对，同 seed 同 config，removing/placing/kidnapping
  ×3 序列：
  - M1 静区 PSNR（psnr_static_cons）≥ v3+2dB
  - M2 depth L1 ≤ v3×0.8
  - M3 事件后凹陷恢复更快（凹陷半宽/深度）
  - 保护读数：事件前静态段与 kidnapping 静态段不退化（±0.3dB）
  - 安慰剂门禁：P1（随机时间戳账本，同剂量）必须无效（|Δ|<0.5dB）
- **配置**：C0=baseline_v3 复跑；P1=安慰剂账本；M-a=退场门控（证据 EMA 衰减
  → sigmoid 不透明度乘子 ×(0.9^age)，低于阈值剪枝）；M-b=M-a+入场门控
  （残差致密化新点先以"试用期"低不透明度入场，累计 ≥K 次静态一致才转正）。
- **预期**：M-a 主要吃 M2（残影深度污染）；M-b 主要吃 M1（静区锐度，
  减少壳体遮挡后 RGB 优化不受污染梯度拖累）；若两臂都不过安慰剂门禁 →
  机制在离线语境无因果效应，止损并记录（E0 单遍递增协议作为备选假设）。
